## EP.01 — 일곱 가지 일

**타겟** 여기 누가 오는지 궁금했던 사람
**성격** 첫 편. 여기가 **어떤 곳인지**를 정한다. 가격은 맨 뒤 한 줄만.

**1장 (썸네일)**
- 위: 여기 누가 오는지 궁금했던 사람에게
- 대문: **일곱 가지 일**
- 부제: 작업실은 개발자만 가는 곳이라고 생각하셨다면
- 사진: 자리마다 놓인 물건이 다 다른 컷 (붓, 노트북, 책, 서류). 사람 없어도 됨

**2장**
```
가오픈 동안
이 자리에 앉았던 사람들입니다.

미술 공부하는 학생.
퇴근하고 오는 직장인.
독서모임을 여는 모임장.
개발자.
디자이너.
사업을 준비하는 사장님.

그리고 칵테일바 사장님.
```
> 일곱 줄 = 대문의 '일곱 가지 일'. 목록을 고치면 숫자도 같이 고친다.
> 제일 안 어울리는 사람을 맨 끝에. 앞을 다 읽게 만드는 건 마지막 한 줄이다.
> 실제로 오신 분만 넣는다. 한 사람을 표지에 세우면 그 사람 얘기로 읽힌다.

**3장**
```
같은 층에서 몇 시간 있으면
서로 뭘 하는 사람인지 알게 됩니다.

사업 준비하시던 대표님은
명함 시안을 디자이너분께 보여드렸고,

독서모임 대표님은
모임 장소가 해결됐습니다.

둘 다 제가 소개해 드린 게 아닙니다.
```
> 가오픈 때 실제로 있었던 일. 마지막 줄이 핵심 — 운영자가 붙여 준 게 아니라
> 그냥 같이 앉아 있어서 생긴 일이어야 "여기 가면 나도"가 된다.

**4장 (고정)**
```
저는 충장로에서 작업실을 운영합니다.

저도 카페를 전전했고,
지금은 매일 누가 어디에 앉는지 봅니다.
```
> 12편 내내 글자 하나 바꾸지 않는다. 사진도 매 편 같은 것을 쓴다.

**5장**
```
혼자 일하면
잘 가고 있는지 알 수가 없습니다.

옆자리에서 전혀 다른 일을 하는 사람이
그걸 알려줍니다.

말을 많이 섞지 않아도 그렇습니다.
```
> 마지막 줄 필수. 커뮤니티를 앞세우면 내향적인 사람이 떨어져 나간다.

**6장**
```
충장로 2층입니다.

앱에 멤버 명함첩이 있습니다.
옆자리가 뭘 하는 사람인지
먼저 물어보지 않아도 알 수 있게.

혼자 오셔도 되고
모임으로 오셔도 됩니다.
```

**7장**
```
3시간 14,000원. 커피 한 잔이 들어 있습니다.
처음 오시면 그거면 충분합니다.

프로필 링크에서 날짜만 고르면 됩니다.
충장로5가 96-23, 2층
```

## EP.02 — 4,000원

**타겟** 커피 한 잔으로 네 시간 버티는 사람

**1장 (썸네일)**
- 위: 커피 한 잔으로 네 시간 버티는 사람에게
- 대문: **4,000원**
- 부제: 싸게 일한 게 아니라, 눈치로 낸 겁니다
- 사진: 다 마셔서 얼음만 남은 잔 하나, 그 옆 노트북. 뒤로 사람들

**2장**
```
커피 한 잔 4,000원.

네 시간을 앉아 있었습니다.

싸긴 쌉니다.
```
> 잔 수로 계산하지 않는다. 한 잔이라고 먼저 인정하고 시작한다.
> 4,000원은 충장로 평균가.

**3장**
```
대신 이걸 냈습니다.

옆 테이블 대화 소리.
짐 때문에 못 가는 화장실.
콘센트 있는 자리 뺏기기.
사람 몰리면 드는 생각 — 슬슬 일어나야 하나.
```
> 네 줄 전부 우리가 실제로 해결해 주는 것만.

**4장**
```
저는 충장로에서 작업실을 운영합니다.

「운영자 실제 이유 한 줄 — 매 편 동일」
```

**5장**
```
문제는 돈이 아니었습니다.

앉을 수 있는 자리 말고
안 비켜도 되는 자리가
필요한 겁니다.
```

**6장**
```
3시간 14,000원. 커피 한 잔이 들어 있습니다.

커피값보다 10,000원 더 냅니다.
그걸로 사는 것.

· 예약한 순간부터 확정된 내 자리
· 짐 두고 나갔다 와도 되는 자리
· 자리마다 콘센트
· 아무도 안 비키라고 하지 않는 3시간
· 모자라면 1시간 4,000원에 연장
```

**7장**
```
프로필 링크에서 날짜만 고르면 됩니다.

충장로5가 96-23, 2층
08:00 – 다음 날 01:00
```

## EP.03 — 하루 2시간

**타겟** 재택근무 3개월 차

**1장** / 위: 재택근무 3개월 차인 사람에게 / 대문: **하루 2시간** /
부제: 집에서 일이 안 되는 건 의지 문제가 아닙니다 /
사진: 이불 위 노트북, 혹은 아무도 없는 창가 자리

**2장**
```
출근이 없어지면
하루가 늘어날 줄 알았습니다.

줄었습니다.
```

**3장**
```
침대에서 책상까지 세 걸음.

그 세 걸음이
하루를 시작 못 하게 합니다.

오전이 통째로 사라집니다.
```

**4장** — 위 고정 문구 그대로

**5장**
```
집중은 의지가 아니라
장소가 만듭니다.

출근이 필요한 게 아닙니다.
일하는 자리가 필요한 겁니다.

집 밖에, 걸어갈 수 있는 곳에.
```

**6장**
```
08:00부터 다음 날 01:00까지 엽니다.

매일 나오실 거면
월권 자유석이 249,000원.

주 6일로 계산하면
하루 10,375원입니다.

커피는 하루 세 잔까지 드립니다.
```

**7장**
```
먼저 3시간만 써보고 정하셔도 됩니다.

프로필 링크 → 날짜 선택
충장로5가 96-23, 2층
```
> 월권은 금액이 커서 바로 안 산다. 3시간권을 문턱으로.

## EP.04 — 1인 25,000원

**타겟** 6명 모일 곳을 찾는 모임장·팀플 조장

사진: 6인 테이블 전체 컷 (사람 없어도 됨, 자리 배치가 보이게)

**2장**
```
여섯 명이 카페에 갑니다.

붙은 자리가 없어서
두 테이블로 나눠 앉습니다.

들리지도 않습니다.
```

**3장**
```
여섯 명이 두 시간 앉으면
음료값만 3만 원 가까이 나옵니다.

그러고도 눈치는 봅니다.
발표 연습은 못 합니다.
```

**4장** — 위 고정 문구 그대로

**5장**
```

시간을 빌리는 겁니다.

몇 시부터 몇 시까지는
우리 것이어야 합니다.
```

**6장**
```
6인 이상 대관, 3시간 기준 1인 25,000원.

음료와 간단한 핑거푸드는 가져오셔도 됩니다.
주류와 음식 반입은 안 됩니다.

일요일 대관은 문의 주시면
날짜를 열어드립니다.
```
> 규칙을 숨기지 않는다. 미리 말하면 신뢰, 당일에 말하면 사고.

```
날짜부터 잡으세요.

문의 070-8211-1734
```
